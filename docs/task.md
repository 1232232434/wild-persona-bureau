## 6. AI 协作工作流

### Workflow A 新功能开发

1. 读取 `spec.md` 对应范围
2. 读取 `plan.md` 中的技术约束
3. 明确改动边界
4. 查阅现有文件
5. 使用 `apply_patch` 实现改动
6. 运行本地构建或验证
7. 输出变更说明

### Workflow B 视觉页面开发

1. 先确认页面属于 MVP
2. 再确认风格是否符合“实验室 + 图鉴”
3. 先结构，后动效，最后细节
4. 保证移动端和桌面端都可浏览

### Workflow C Prompt / AI 开发

1. 明确输入结构
2. 明确输出字段
3. 优先固定 JSON 字段
4. 先做本地回退，再接真实 AI
5. 设计异常降级逻辑

### Workflow D 联调验证

1. 检查环境变量
2. 检查代理地址
3. 验证返回 JSON 字段
4. 验证 fallback 是否正常
5. 验证错误信息是否可读
6. 记录结果与风险
